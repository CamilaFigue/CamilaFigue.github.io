# Camila Figueroa · Tarjeta de presentación

Tarjeta de presentación profesional online.

🔗 **https://camilafigue.github.io**

## Sobre mí

Desarrolladora de Software en Rosario, Santa Fe, Argentina. Me especializo en integrar y automatizar sistemas empresariales: interfaces web con JavaScript y Vue.js, integración de APIs REST y SOAP, ERPs como Protheus y administración de ambientes DEV, QA y PROD.

## Qué incluye la página

- Presentación con nombre, rol, ubicación y una bio breve.
- Email visible con un botón para copiarlo al portapapeles.
- Acceso directo a mi perfil de LinkedIn.
- Mi stack de tecnologías organizado por áreas.
- Diseño claro y minimalista que se adapta a celulares y computadoras.

## Tecnologías

- **HTML5** y **CSS3**: Flexbox, Grid, variables CSS y media queries.
- **JavaScript** sin frameworks: copiado del email con la Clipboard API y una alternativa para navegadores que no la soportan.
- **Google Fonts**: Fraunces e Inter.
- **GitHub Pages** para el hosting.

Todo el sitio está en un solo archivo (`index.html`), sin dependencias ni pasos de compilación.

## Verlo en tu computadora

```bash
git clone https://github.com/CamilaFigue/CamilaFigue.github.io.git
```

Después abrí `index.html` en cualquier navegador.
